# wgs-release-validation

Release validation for a WDL germline variant-calling workflow: every change is benchmarked against
the Genome in a Bottle (GIAB) truth set for HG002, gated against a committed baseline, and written
up the way a release would be signed off for customers.

!!! warning "Research use only"
    This is a portfolio project, not a clinical pipeline. It benchmarks one public reference sample
    on one region of chromosome 20. Customers named in the case studies are fictional; all data,
    runs and numbers are real.
