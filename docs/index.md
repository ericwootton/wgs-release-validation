# wgs-release-validation

For release validation of the WDL germline variant-calling workflow, every change is benchmarked
against the HG002 Genome in a Bottle (GIAB) truth set. Whether a change passes is determined using
the committed baseline. This is documented in the format that would be used for customer-facing
release approval.

!!! warning "For research use only"
    This portfolio project is not an analysis workflow for clinical use. Benchmarking was performed
    using a single public reference sample within a single region of chromosome 20. All customers in
    the case studies are fictional, while the data, run results, and numerical values are real.
